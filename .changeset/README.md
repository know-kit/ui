# Changesets

Use `pnpm changeset` to create a release note for changes that should bump package versions.

Use `pnpm changeset:version` to apply pending version bumps with the official git-based changelog plugin.

Use `pnpm changeset:publish` to publish the released packages.

The package changelogs are generated by Changesets. The repository-level
`RELEASE.md` is generated from Conventional Commits:

```bash
# First release, before the repository has a version tag
pnpm changelog:first-release

# Later releases, from the latest SemVer tag to the current commit
pnpm changelog

# Preview without changing files
pnpm changelog:preview
```

Create a version tag after the release is published so the next changelog has
a stable starting point, for example `v1.0.0`.
